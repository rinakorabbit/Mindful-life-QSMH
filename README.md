# Mindful Life QSMH - ระบบลงทะเบียนกิจกรรมการพัฒนาจิตเพื่อคุณภาพชีวิต

ระบบเว็บแอปลงทะเบียนพร้อมแดชบอร์ดตรวจสอบรายชื่อ (เรียง ก-ฮ) และส่งอีเมลยืนยันอัตโนมัติ  
พัฒนาขึ้นสำหรับ **งานกิจกรรมวิชาการและการจัดการความรู้ ฝ่ายวิชาการและวิจัย โรงพยาบาลสมเด็จพระบรมราชเทวี ณ ศรีราชา สภากาชาดไทย**

## คุณสมบัติเด่น (Features)
- **ระบบหมุนเวียนรอบจัดงาน (2 ครั้ง/ปี):** สลับรุ่นและวันที่จัดงานได้ทันทีผ่านแผ่นงาน `Config` ใน Google Sheets โดยไม่ต้องแก้โค้ดหรือ Deploy ซ้ำ
- **ระบบตรวจสอบโควตาอัตโนมัติ:** แจ้งเตือนและปิดรับทันทีเมื่อจำนวนผู้ลงทะเบียนครบตามจำนวนที่กำหนด
- **ส่งอีเมลยืนยันผลทันที:** ส่งรายละเอียดโครงการ วันที่ เวลา สถานที่จัด และข้อมูลติดต่อเข้าสู่อีเมลผู้ลงทะเบียน
- **แดชบอร์ดรายชื่อเรียงตาม ก-ฮ:** แสดงเฉพาะชื่อ-นามสกุล เพื่อความเป็นส่วนตัวและความสะดวกในการตรวจสอบสิทธิ์
- **Accessible & High-Contrast Design:** พื้นหลังพาสเทลสไตล์ธรรมชาติ-ธรรมะ ตัวหนังสือขนาดใหญ่ อ่านง่าย เหมาะสำหรับผู้สูงอายุ

## ขั้นตอนการติดตั้งบน Google Apps Script
1. ไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. คัดลอกโค้ดจาก `Code.gs` วางลงในตัวแก้ไขสคริปต์
4. กดปุ่ม `+` ข้างหัวข้อ **ไฟล์ (Files)** เลือก **HTML** ตั้งชื่อว่า `Index` แล้ววางโค้ดจาก `Index.html`
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - การดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
6. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** และนำ URL เว็บแอปไปใช้งานได้ทันที

## การสลับรอบกิจกรรม (สำหรับผู้ดูแลระบบ)
เมื่อต้องการเปิดรับสมัคร **รอบที่ 2 หรือปีถัดไป**:
1. เปิด Google Sheets เข้าไปที่แท็บแผ่นงาน **`Config`**
2. แก้ไขค่าในคอลัมน์ `Value`:
   - `Active_Batch` : เปลี่ยนชื่อรอบ เช่น `รุ่นที่ 2`
   - `Event_Date` : ใส่วันที่จัดจริง เช่น `วันศุกร์ที่ 28 สิงหาคม 2570`
   - `Max_Quota` : กำหนดจำนวนรับสูงสุด
   - `Is_Open` : ใส่ `YES` เพื่อเปิดรับ หรือ `NO` เพื่อปิดรับ
3. หน้าเว็บแอปและอีเมลจะเปลี่ยนข้อมูลตามรอบใหม่ทันที
