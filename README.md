# Mindful Life QSMH - ระบบลงทะเบียนกิจกรรมการพัฒนาจิตเพื่อคุณภาพชีวิต

ระบบเว็บแอปลงทะเบียนพร้อมระบบส่งอีเมลยืนยันอัตโนมัติ และ Dashboard แสดงรายชื่อเรียงตามตัวอักษร ก-ฮ  
พัฒนาขึ้นสำหรับ **งานกิจกรรมวิชาการและการจัดการความรู้ ฝ่ายวิชาการและวิจัย โรงพยาบาลสมเด็จพระบรมราชเทวี ณ ศรีราชา สภากาชาดไทย**

---

## จุดเด่นของระบบ (Key Features)
1. **Banner Website พาสเทล ม่วง-ชมพู-เหลือง:** สื่อถึงความสงบ สบายตา พร้อมสัญลักษณ์ดอกบัว 3 ชั้น
2. **ระบบ Config สลับรอบจัดงาน 2 ครั้ง/ปี:** ผู้ดูแลระบบเปลี่ยนข้อมูลรอบจัดงาน วันที่ เวลา และโควตาได้โดยตรงผ่าน Google Sheets โดยไม่ต้องแตะโค้ด
3. **ระบบตรวจสอบโควตาและปิดรับอัตโนมัติ:** เมื่อมีผู้ลงทะเบียนครบตามจำนวนที่กำหนด ระบบจะปิดรับสมัครทันที
4. **ระบบส่ง Email ตอบกลับอัตโนมัติ:** แจ้งสรุปข้อมูลการลงทะเบียน พร้อมรายละเอียดสถานที่และข้อมูลติดต่อ
5. **Dashboard ตรวจสอบรายชื่อ ก-ฮ:** แสดงเฉพาะชื่อ-นามสกุล ของรอบปัจจุบันเพื่อความปลอดภัยและความเป็นส่วนตัว
6. **ออกแบบเพื่อผู้สูงอายุ (Elderly-Friendly UI):** ตัวอักษรหนา ขนาดใหญ่ ชัดเจน อ่านง่าย

---

## ขั้นตอนการติดตั้งใช้งานบน Google Apps Script
1. ไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. คัดลอกโค้ดจาก `Code.gs` วางลงในไฟล์สคริปต์
4. กดปุ่ม `+` ข้างหัวข้อไฟล์ แล้วเลือก **HTML** ตั้งชื่อไฟล์ว่า `Index` จากนั้นนำโค้ดจาก `Index.html` ไปวาง
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - การดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
6. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** และนำ URL เว็บแอปไปประชาสัมพันธ์ได้ทันที

## วิธีการเปลี่ยนรอบกิจกรรม (สำหรับผู้ดูแลระบบ)
เมื่อถึงเวลาเปิดรับสมัครรอบใหม่ (เช่น รอบที่ 2 ของปี):
1. เปิดสเปรดชีต แล้วไปที่แท็บแผ่นงาน **`Config`**
2. แก้ไขช่องในคอลัมน์ `Value`:
   - `Active_Batch` : ชื่อรอบ เช่น `รุ่นที่ 2`
   - `Event_Date` : วันที่จัด เช่น `วันศุกร์ที่ 28 สิงหาคม 2570`
   - `Event_Time` : เวลาที่จัด
   - `Event_Place` : สถานที่จัด
   - `Max_Quota` : โควตาผู้เข้าร่วม
   - `Is_Open` : ใส่ `YES` เพื่อเปิดรับ หรือ `NO` เพื่อปิดรับ
3. บันทึกแล้วเสร็จสิ้น หน้าเว็บแอปและระบบอีเมลจะเปลี่ยนไปใช้ข้อมูลรอบใหม่ทันที
